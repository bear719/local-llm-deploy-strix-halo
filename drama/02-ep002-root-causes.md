### 核查方法（值得抄）

| 手段 | 用途 |
|---|---|
| 逐镜首/中/尾抽帧拼图 | 构图、景别、道具形态、脸型 |
| 音轨能量分析（RMS） | 「听不清」到底是被截断还是音量低 |
| 基频 F0 统计 | 说话人性别/个体粗筛（男女、个体音域） |
| 梅尔倒谱 DTW | 说话人身份匹配（与参考音色做动态时间规整距离） |
| `--ref-audio` 参数核对 | 确认绑定关系本身对不对（本例完全正确） |

> ★ 「听不清」有两种完全不同的根因：**被截断**（时长不够）和**电平太低**（音量不够）。
> 靠耳朵分不出来，必须看 RMS + 看时间轴。

## 二、六条系统性根因

### A. 关键帧丢机位（影响面最大）

**现象**：视频提示词写了「机位在对方肩后，前景是一侧虚化的肩背与侧脸轮廓」，
但成片是主角正面中景。

**根因**：`camera_zh` 把「机位 + 运镜」拼在同一根字符串里，
而 `_build_keyframe_prompt()` **根本不接收该字段**（关键帧阶段刻意剥离了运镜句，
以避免首帧锁死机位）。

于是：视频侧写「过肩」，关键帧侧画成正面中景 → 首帧锁死 → 后续推近也救不回来。

凡是要求特殊首帧构图的镜（过肩 / 反打 / 门缝局部）都中招。

**修法**：把「静态机位」与「运动」分离，关键帧只吃静态部分。

```
camera_zh ──▶ angle_zh（静态机位）──┐
          └─▶ camera_zh（运镜）      ├──▶ 关键帧（只吃 angle）
                                    └──▶ 视频提示词（两个都吃）
```

新增 `angle_for()` 与静态机位规则表；
`_strip_camera_phrases()` 改为**分句分类**：运动句丢弃、机位句转写保留。

### B. 分号截断丢掉落幅人物 → 换脸

**根因**：`_first_beat_action()` 对长镜只取起幅（第一个分号前的部分）。
某镜的「主角凑近的脸显出来」在被截掉的后半段 →
被判为道具镜 → 清空人物锚 → 落幅自由生脸。

注意：视频侧**确实传了**主角定妆照（`-r 首帧.png 主角.png`），
但首帧里没有这个人，H3 对后段冒出来的脸没有身份约束，于是自由生成。

**修法**：三层分工，各管一段。

| 字段 | 判据 | 用途 |
|---|---|---|
| `ref_characters` | **完整**动作里出现过谁 | 视频侧身份锚（`<Subject N>`） |
| `kf_ref_characters` | **起幅**里就有谁 | 关键帧侧身份锚（`-r`） |
| `kf_prop_refs` | 起幅明确出现的道具 | 道具图像锚 |

### C. 道具完全无锚定 → 一镜三样

道具在三个镜里是三样东西：褐色小壶 → 橄榄绿小罐 → 灰白大陶罐。
人物有定妆照走 `-r`，**道具没有任何锚定手段**。

**修法**：三级锚定。

| 可见程度 | 锚定方式 | 例 |
|---|---|---|
| 完全可见 | **图像锚**（`-r` 道具定妆照） | 手心捧瓶、倾倒 |
| 部分可见 | **仅文字锚**（固定外观逐字重复） | 袖口里隐约透出暗影 |
| 完全不可见 | **不锚定，且剧本里不写该物名** | 瓶子藏在身后 |

道具定妆照由脚本生成 + `_meta.json`（含别名表）：
「深绿偏灰哑光粗陶、瓶口有豁口、不透明无反光」。

> ★ 关键经验：**只要在动作文本里写出道具名字，模型就会画出来。**
> 第一版改写后仍写「那枚巴掌大的暗绿粗陶小瓶完全藏在他的背后、袖口里」，
> 瓶子照样出现在腋下。改成「只写形不写物」后才消失。
>
> ★ 配套兜底：道具别名匹配失手时（剧本为了「只露一点暗影」而不写名字），
> 从定妆照的 `look` 里提取**颜色特征词**（墨绿/暗绿/深绿/青绿/苍绿/绿偏灰），
> 剧本里出现任一即视为提及，避免文字锚脱落。

### D. 台词截断

**根因**：台词排在动作之后（提示词写「**随后**说」）→ 起播拖到 4.10 s；
且镜长下限只保证「塞得进去」，不保证「念完还剩一口气」。

**实测标定**（同一集 21 镜语音分析）：

| 量 | 实测范围 | 中位 |
|---|---|---|
| 语速 | 1.60 – 8.77 字/秒 | **3.60** |
| 起播时刻 | 0.02 – 4.10 s | — |

**决定性关联**：

| 尾部余量 | 镜数 | 用户反馈 |
|---|---|---|
| **≤ 0.16 s** | 5 镜 | **全部被投诉「话没说完」** |
| ≥ 0.33 s | 6 镜 | 全部完整 |

**修法**：

```python
_DIALOGUE_CHARS_PER_SECOND = 3.4    # 实测中位 3.60，取 3.4 略保守
_DIALOGUE_LEAD_IN = 0.5             # 台词前置后起播实测 ~0.3–0.5s
_DIALOGUE_TAIL = 0.5                # ★ 念完必须留的尾部余量
```

措辞 `随后…说` → **`开口即说`** + 「整句台词在本镜前三分之一的时间内说完」，
台词块**前置**到画面动作之前。

### E. 人声音量过低

**根因**：某镜台词 RMS 0.0228，对照镜 0.1012（1/4）—— 画外音被当环境声处理了。

**修法**：新增音量约束「**本镜人声是主音源，音量明显高于环境音**」。

### F. 关键帧与清单漂移

**根因**：PNG 生成于 08:59，清单 09:16 才更新 → 图与提示词不是一对。

**修法**：统一重建流程（清单 → 关键帧 → 逐张复核 → 渲染）+ 指纹守卫。

## 三、人物三态：收尾句的最后一处矛盾

**问题**：收尾句只判「是否道具镜」，于是**空镜**（人物列表为空但不是道具镜，
如「门缝下的鞋」）同时拿到两句互相矛盾的话：

- 正文：「画面中不出现人物，只呈现环境与物件」 ← 否定
- 收尾：「人物面部清晰、五官端正」 ← **正向词**

扩散模型里**正向词的分量高于否定句** → 模型照收尾句画了一张脸。
用户的原话是「门缝中的主角感觉像镜子中的」。

**修法**：拆成三态，且**判定顺序有讲究**。

```python
if back_only:                      portrait = SILHOUETTE   # ★ 必须排第一
elif prop_only or not who:         portrait = NONE
else:                              portrait = FACES
```

> ★ 为什么 `back_only` 必须排第一：**背影镜的人物列表天然为空** ——
> 大全景/远景会被景别规则排除（不给背影挂定妆照，否则模型给背影安一张正脸）。
> 若按「who 为空 → 无人」判定，背影镜会拿到「画面中不出现人物」，
> **恰好把那个身影抹掉**。

同步改了角色外观注入脚本的复用分支（新增 `_infer_portrait()`），
避免用默认 `faces` 重刷回矛盾状态。

## 四、台词归属重排

原剧本把两句台词放在同一镜，但前一句回应的是**上一镜**的动作。

**重排为三镜**：

| 镜 | 画面 | 台词 | 说话人 |
|---|---|---|---|
| 008 | 反派半垂的手先入画，随后是他的脸——他在笑 | 给你带了个东西。 | 反派（在场） |
| 009 | 匣盖掀开，匣内枯死灵草、发黑根须 | 烧得这么急。 | 反派（**画外音**） |
| 010 | 反派俯身在匣边，脸从油灯光里抬起 | 三日后，我要看到它返青。 | 反派（在场） |

音色锚经 DTW + F0 双重验证，009/010 的 `--ref-audio` **本就是**反派音色，
用户第 9 条反馈属实。

但 **0.61 s 极短语音是音色迁移弱的固有限制** ——
音色参考需要足够上下文长度才能稳定迁移，一句话被单独切出来时最容易滑回默认音色。
已通过「把台词拆开 + 各自给足时长」缓解。

## 五、第二轮：关键帧复核暴露的七个「提示词自相矛盾」

第一轮修完管线，重新生成 21 张关键帧，逐张目视复核又暴露 7 个新问题。
共同特征：**单看每句都通顺，放在一起就打架。**

### 5.1 「笑」字是正向触发词

定妆照写「笑时眼角不动」，模型读到「笑」就画了**露齿大笑**。否定句「不露齿」压不住。

修法：改成正向几何描述

```
嘴唇始终闭合、看不见牙齿，嘴角平直不起弧，面部肌肉松弛、眼神沉静
```

并把剧本里「他在笑 / 笑的时候眼角没有动」改写成
「嘴角只是极轻微地向上牵了一下，嘴唇始终闭合，看不见牙齿，眼角的纹路平直得一动没动」。

### 5.2 长镜起幅截断会丢掉构图硬约束

`_first_beat_action()` 对 ≥7.5 s 的长镜只取起幅，而方位信息
（「画面左侧靠墙的草席上坐着主角」「右侧站着反派」）在**第二拍**里 → 整段被截掉 →
关键帧把主角画成**站着**并排站在反派旁边。

修法：起幅之后若还有含方位/姿态关键词的节拍，一并并入起幅（**最多再取一拍**）。

### 5.3 通用双人构图模板会覆盖剧本的方位指令

通用句「一个在前景、一个在后景，前后错开」与本镜的「一坐一站、左右分置」冲突，
模型取了默认值。

修法：剧本若已给出**画面坐标/姿态**（左/右/上/下、坐/站/跪/趴），
只补「不得并排、不得同时正对镜头」，**不再叠加会打架的默认构图**。

### 5.4 局部特写镜提到角色名 ≠ 画面里有这个人的脸

剧本写「紧贴主角左腕的袖口内侧」→ 动作里有主角的名字 →
旧判定认为不是道具镜 → 挂了主角定妆照 → 模型画了一张**清晰正脸**占满画面。

修法：`prop_only` 增加一条判据 —— **动作文本里明写排除脸/身体**时，按道具镜处理。

### 5.5 纯表面特写镜不能套用空间景深模板

动作写「整幅画面只有这一块木料，占满全部画幅」，
但通用景深模板又说「前景是虚化的门框边缘…背景是可辨认的真实环境（土墙、木桌、陶罐，
或门外月光下的石阶、树影、院墙）」→ 模型画出了**半开的门**、
两侧漏出屋内桌子油灯和院子。

修法：景深生成增加 `_flat_surface` 判定 —— 表面镜改用
「极浅景深…画面里没有背景、没有纵深、没有第二样东西」，
并新增一版不含「门框」这个词的防镜像规则（禁止词本身也会被画出来）。

### 5.6 剧本里写了道具名，模型就会画出它

见铁律二。改为**只写形不写物**：

```
手掌在腰后攥紧成拳，袖口被撑起一小块硬的方形隆起，
看得见布料的褶皱，却看不见掌心里握着什么
```

### 5.7 道具别名匹配失手时的兜底

剧本为「只露一点暗影」而不写道具名 → 别名表匹配失败 → 文字锚脱落 →
暗影颜色与定妆照脱钩。

修法：增加**颜色特征兜底**（见根因 C 末尾）。

## 七、这一轮最贵的教训

**修复成本是复利的。**

只修第一轮（管线层，不动剧本），17 条反馈里仍有大量残留；
而每重渲一镜的代价是 20–35 分钟。这一轮最终重渲 11 镜约 1500 帧、
按 9.5 秒/帧 ≈ **4 小时**，另加 11 张关键帧重生成约 40 分钟。

**正确的顺序是**：

```
1. 先把剧本写对（方位、姿态、台词归属、道具可见性）
2. 再生成关键帧，逐张目视复核（这一步最便宜，一张图几分钟）
3. 关键帧全部合格后才开始出视频
```

跳过第 2 步直接出视频，等于用 4 小时的算力去检验一张几分钟就能看清的图。
