`/metrics` 的 `spec_decode_*_total` 是**进程级累计**，重启即归零。重启后 2 小时内的累计值样本量小、方差大，**不能与前一日的稳态值比较趋势**。

判据固化：比较接受率前先看进程 `lstart`；当天有重启 → 前一日稳态值作废，次日再看。
