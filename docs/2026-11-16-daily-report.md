## 二、★ `--moe-cache-mib` 生效条件（A1 候选作废）

多源交叉后确认的机制：

1. 缓存只对**留在主机内存的专家权重**有意义，必须配合 `-cmoe` / `-ncmoe` / `-ot` 让部分专家层不上显存；
2. 且只对 **≤32 token batch（decode 阶段）**生效，prefill 阶段无效；
3. 若 `-ngl` 全 offload，导致"没有任何层的专家留在主机内存"，llama.cpp 会**警告并自动禁用缓存**。

本机 `-ngl 999` 全 offload → **单独追加 `--moe-cache-mib` 大概率零效果**。

**正确做法**：不要直接加 flag，先做 A/B —— A 组保持 `-ngl 999`（基线），B 组用 `-ncmoe` 把若干 MoE 层留在主机内存后再开缓存，比对 decode。作者在 RTX 5090 上报 2.2×（命中率 89%），但双卡测试者反而变慢 → **不可跨硬件外推**。
