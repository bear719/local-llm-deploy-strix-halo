## 先说结论：十条最贵的经验

按「踩进去会损失多少时间」排序。

| # | 经验 | 代价 |
|---|---|---|
| 1 | **关键帧必须吃机位信息**。视频提示词写了「过肩」，关键帧却画成正面中景 → 首帧锁死，推近也救不回来 | 影响面最大，几乎每镜中招 |
| 2 | **否定句在扩散提示词里几乎无效**。要什么就正面写出来，不要写「不 X」 | 3 处「笑」被画成露齿大笑 |
| 3 | **不要在动作文本里写出道具名**。写了模型就画出来，哪怕写的是「藏在背后」 | 道具一镜三样 |
| 4 | **台词要前置，且必须留尾部余量**。余量 ≤0.16s 的 5 镜全被投诉「话没说完」 | 需重渲 11 镜 ≈ 4 小时 |
| 5 | **sd-cli 的 `--seed` 默认 42**。不传 `-s` 时全片每镜每段同一个种子 → 重演 | 分段重演，白烧算力 |
| 6 | **首/尾帧硬锁与 `-r` 参考互斥**。要身份锚定就没有首帧锁，反之亦然 | 决定整条路线取舍 |
| 7 | **H3 按时长铺满音频**。富余超过一半就拿富余去念 prompt 里的画面描述 | 串音 |
| 8 | **帧数只能是 `5 + 17k`** | 时长不能随便设 |
| 9 | **1 步产物的音频不能用于任何音频判断**（ASR 识别出一串「喵」） | 音频质检必须 ≥8 步 |
| 10 | **一镜 1 主 + 1 转 + 1 结**。压镜后拼 2–3 个动作，模型会在镜内自行跳切 | 镜内跳切 |

## 两条贯穿全篇的硬铁律

### 铁律一：正向描述 > 负向否定

扩散模型（尤其 `cfg_scale=1.0` 的 guidance-distilled 模型）**没有有效的无条件下分支**，
负向词基本失效。而且在 CFG=1.0 下，**正向词的分量远高于否定句**。

错误示范：

```
他在笑，笑的时候眼角没有动，不露齿
```

模型读到的正向信号是「笑」→ 画出露齿大笑，「不露齿」压不住。

正确写法：

```
嘴唇始终闭合、看不见牙齿，嘴角平直不起弧，面部肌肉松弛、眼神沉静
```

**只写你要的样子，不写你不要的样子。**

### 铁律二：写了什么就会画出什么

动作文本里出现的每一个名词，都是模型的绘制指令。

```diff
- 那枚巴掌大的暗绿粗陶小瓶完全藏在他的背后、袖口里
+ 手掌在腰后攥紧成拳，袖口被撑起一小块硬的方形隆起，
+ 看得见布料的褶皱，却看不见掌心里握着什么
```

原写法虽然语义是「藏」，但「暗绿粗陶小瓶」这个名词在场 → 模型在腋下画了一只瓶子。
改写后**只写形不写物**，瓶子才真的消失。

同样地，「数十名弟子」这种数量描述会被理解为「填满画面」，
每张小脸都要分配算力 → 必然崩。改成「≤8 人、焦外、只留轮廓色块、不出现正对镜头的清晰五官」。
